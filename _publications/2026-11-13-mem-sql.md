excerpt: "Propose MEM-SQL, a memory framework that reuses verified SQL templates, components, and schema mappings, consulting the database schema only when historical evidence is insufficient. Across six language models on HARE, our historical SQL reuse benchmark, MEM-SQL improves mean execution accuracy from 37.1% to 50.0%. Compared with direct generation without history, it reduces input tokens by 76.6% and latency by 68.8% on average."
